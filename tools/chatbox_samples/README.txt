VRCT Chatbox Sample Player — Windows x64
=======================================

チャットボックス検出モデルの学習画像を作るための、多言語サンプル送信ツールです。
PythonやVRCT本体は不要です。サンプル本文はこの用途向けに作成した架空の会話です。

【別PCでの使い方】
1. ZIPを全部展開し、書き込み可能なフォルダに置きます。
2. そのPCで送信役のアカウントを使ってVRChatを起動します。
3. 撮影役と送信役が同じインスタンスに入ります。
4. 送信役のVRChatのアクションメニューからOSCを有効にします。
   初期設定の入力ポート9000を使います。変更した場合は下の--portを指定します。
5. VRCT-Chatbox-Sample-Player.exeをダブルクリックします。
   最初は待機しています。Enterを押すとチャット送信を開始します。
   6秒ごとにサンプルをシャッフルして繰り返し送信します。
6. 撮影側PCの収集ツールを起動し、送信役のチャットボックスを撮影します。

送信先は実行中のPCの127.0.0.1です。撮影側PCでこのexeを実行すると、
撮影側のアカウントが話してしまうので、必ず送信役のPCで実行してください。
OSC送信ツールが複数動いていると表示を上書きし合うため、他の送信を止めてください。

【キー操作】
コンソールにフォーカスを置いて操作します。開始後はEnter不要です。
P: 一時停止／再開、QまたはCtrl+C: 終了、R: 送信件数・状態。
開始前の取り消しはQを入力してEnter。終了後はEnterで画面を閉じます。
停止しても最後のチャットは表示時間が終わるまで残る場合があります。
通知音はOSCの引数で無効にしています。

【サンプル】
20言語と、言語混在・数字・句読点・絵文字・顔文字・改行の例を含みます。
日本語、英語、韓国語、中国語（簡体字／繁体字）、スペイン語、フランス語、
ドイツ語、ポルトガル語、イタリア語、ベトナム語、インドネシア語、トルコ語、
ポーランド語、アラビア語、ヘブライ語、ヒンディー語、タイ語、ロシア語、ウクライナ語。
中国語の2表記をそれぞれ1種類として数えています。

tiny=1～5、short=6～30、medium=31～80、long=81～144 UTF-16単位。
144文字の制限を越えないよう保守的に数え、絵文字の一部は2単位として数えます。
最大9行には自動折り返しも含まれるので、明示改行9行でも全文が見える保証はありません。
アラビア語等の方向・結合文字・絵文字は、VRChatのフォントによって正しく表示されない
可能性があります。実際の表示を確認し、読めない例は学習目的に合わせて扱ってください。

samples.txt は人が読む一覧、samples.jsonl は別ツールで読み込むための一覧です。
このexeが実際に読むのはchatbox_samplesフォルダ内の4つのJSONファイルです。
編集後はexeを起動し直してください。元のJSONに不正なサンプルがあると送信前に停止します。
JSONはUTF-8、改行は文字列内に\nと書きます。空文字・制御文字・上限超過は送信しません。
samples.txt/jsonlはビルド時の一覧なので、JSONを編集しても自動更新されません。

【設定例：exeのフォルダでPowerShellから実行】
  .\VRCT-Chatbox-Sample-Player.exe --languages ja,en,ko,zh-Hans --interval 8
  .\VRCT-Chatbox-Sample-Player.exe --length long --once
  .\VRCT-Chatbox-Sample-Player.exe --languages mixed --ordered
  .\VRCT-Chatbox-Sample-Player.exe --port 9000 --max-messages 50
  .\VRCT-Chatbox-Sample-Player.exe --list
  .\VRCT-Chatbox-Sample-Player.exe --dry-run --max-messages 3

通常は開始時にEnter待ちです。--startを明示するとEnterを待たず送信します。
--onceは全サンプルを1周して終了、--max-messagesは送信件数で終了します。
--orderedはファイル順、--seed 42はシャッフルの順番を再現します。
--intervalは6秒が初期値、ツールの下限は3秒です。
--dry-runは画面表示のみで、ソケット作成・OSC送信・ログ保存をしません。
--listも送信しません。引数付き起動は終了時のEnter待ちがありません。

【撮影時の工夫】
・撮影側は相手のチャットボックスが見える設定にします。
・文章だけでなく距離、向き、背景の明暗、アバターの高さを変えてください。
・同じ文の間も少し視点を変えると、似た画像ばかりになるのを減らせます。
・収集ツールは初期設定で10分で止まります。長く撮る場合は--duration 0を指定します。
・送信を一時停止し、表示が消えた状態の背景画像も別途撮影します。
・文章が送信されたという記録は、画像にチャットが写った証明にはなりません。
・学習／評価の分割では、同じ撮影セッションの似た画像を分けないでください。

【送信ログと制約】
sent_logsにUTF-8のJSONLで送信日時（UTC）、サンプルID、本文、宛先等を記録します。
[submitted]はUDPをOSへ渡した意味です。VRChatからの受信・表示確認はできません。
ログは本ツールが送ったサンプルだけで、他人のチャットを収集しません。
このツールは画像のアップロードやGeminiへの送信を行いません。
初回exe起動に時間がかかる場合があります。この配布物は未署名です。
Python未導入の別PCや、VRChat上の全言語の字形は未検証です。
再配布時はlicensesフォルダを含むZIPを渡し、sent_logsを含めないでください。
