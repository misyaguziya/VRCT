Provenance
----------
  Base weights   yolox_tiny.pth (COCO-pretrained, published by Megvii under
                 Apache-2.0 at Megvii-BaseDetection/YOLOX)
  Framework      YOLOX 0.3.0 (Apache-2.0)
  Task           single class detection, class 0 = chat_box
  Input          dynamic HxW, letterbox with the long side at 1280, top-left
                 padding, pad colour 114, BGR, unnormalised 0-255
  Output         [1, anchors, 6] = cx, cy, w, h, objectness, class
                 (grid/stride decode in-graph, NMS on the VRCT side)
  Export         ONNX opset 17, INT8 static quantization (QDQ, per-channel);
                 the prediction convolutions and the decode stay in fp32
