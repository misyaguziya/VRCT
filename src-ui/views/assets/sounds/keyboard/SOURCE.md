# VR キーボードのキーの音

`keypress-001.wav` 〜 `keypress-032.wav` は、unicaegames の
[Keyboard Soundpack #1 [Typing and Single Keystrokes]](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes)
の `Single Keys` (Cherry KC 1000 の録音) から作った。

- ライセンス: CC0 1.0 (パブリックドメイン、https://creativecommons.org/publicdomain/zero/1.0/)
- 変更: 頭の無音を切り (音の立ち上がりの 2 ms 前から)、0.2 秒で終わるよう末尾 20 ms をフェードアウトし、最大音量を -1 dBFS にそろえた
- 番号は元のファイルのまま
