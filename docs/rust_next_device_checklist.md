# Rust 版 次期開発: 実機で確かめること (P0〜P2.5)

2026-11-16 時点 (`rust-full-backend`)。単体テスト・契約テストでは確かめられず、実機 (VR・インストーラ・回線) でだけわかること。
キーボードそのものの操作は `docs/vr_keyboard_vr_checklist.md` に別にある。ここはそれ以外と、P2 以降に変えた点。

## P0: インストーラ
- [ ] システムのプロキシを設定した PC で、インストーラがモデル・DLL を取得できる (#124)
- [ ] アンインストールで `ime` フォルダが残らない

## P1: #127 (文字起こし API の一時的な失敗)
- [ ] 文字起こし API の使用中に回線を一時的に切ると、すぐには止まらず、発話 5 回続けて失敗したときだけ止まる
- [ ] 回線が戻ると、そのまま文字起こしが続く
- [ ] 認証の誤り (401/403) や上限 (429) では、1 回で止まって通知が出る

## P2: オーバーレイの土台
- [ ] VR UI を開いて指している間、トリガー・グリップが VRChat に届かない。指していないときは届く
- [ ] ランチャーを押すと手が振動する
- [ ] SteamVR を強制終了 (タスクマネージャーで vrserver) しても VRCT が固まらない。SteamVR を起動し直すと VR UI が戻る。OCR を ON にしたままでも同じ
- [ ] VRChat に貼り付けたとき、貼り付け先のアプリ名が正しい
- [ ] 日本語のユーザー名の PC で、キーボードの日本語入力 (librime) が落ちない
- [ ] 絵文字や結合文字を ◀▶・BackSpace で 1 字ずつ扱える (書記素単位)

## P2: キーボード辞書の準備
- [ ] VR UI が OFF のままでは、辞書の取得が始まらない (起動しても `ime/shared` が増えない)
- [ ] VR UI を ON にしても、SteamVR が動いていなければ取得が始まらず、VR 画面の窓 (画面外の WebView) も作られない (タスクマネージャーで WebView2 が増えない)
- [ ] SteamVR を起動すると、取得が始まり、進み具合が出て、終わると日本語・中国語が打てる。VR UI も出る
- [ ] SteamVR を終了しても VR 画面の窓は残り (作り直さない)、起動し直すと開いていた窓のまま VR UI が戻る。窓が消えるのは VR UI を OFF にしたときだけ
- [ ] VR UI を OFF → ON にすると、開いていたログ窓・キーボードは開いたまま戻る (言語・設定のポップアップは戻らない)。VRCT を起動し直したときはランチャーだけ
- [ ] 言語メニューだけを開いたまま VR UI を OFF → ON にしても、中身の無いポップアップの板が残らず、その場所で VRChat を操作できる
- [ ] SteamVR を起動し直したときに、VR 画面の撮影が PrintWindow に落ちない (`process.log` に PrintWindow へ切り替えた記録が出ない)
- [ ] VR の設定ウィンドウを開いたまま VR UI を OFF にしても、翻訳・文字起こしが止まったままにならない (デスクトップの設定画面の扱いも戻る)
- [ ] 取得に失敗したとき、キーボードから再試行できる

## P2: 表示倍率 (Windows の「拡大/縮小」100% / 125% / 150%)
- [ ] VR パネルの窓が 1.25 倍・1.5 倍に膨らまない
- [ ] VR パネルの表示が欠けたり、ずれたりしない
- [ ] クリック・ドラッグ・スクロールの位置が、レーザーの当たった位置と合う
- [ ] SteamVR なしの OCR (VRChat の窓を直接撮る) で、窓が欠けず、右下に黒い余白が出ない
- [ ] 100% で今までと変わらない
- [ ] 倍率の違う 2 枚のモニターで、VR パネルの窓が別のモニターに置かれても崩れない

## P2: キーボードの見た目 (今の MSKB に合わせた点)
- [ ] 候補をすばやく押して離すと確実に選ばれる (手ぶれがあっても)。100% と 150% の両方で
- [ ] 候補が多いとき、帯を掴んでスライドできる。スティックで横に送れる。Space で次の候補に移すと見える所までずれる。‹ › が隠れない
- [ ] 候補を押したまま、もう片方の手でキーを押すと、その候補は選ばれない
- [ ] 候補を押したまま VR の画面の外へ抜けても、帯が跳ねない
- [ ] Ctrl を押している間、⌫ が灰色で押せない
- [ ] 言語メニューと歯車のパネルの影の見え方

## P2.5: ログ窓の字幕の形
- [ ] 操作バーの形のボタンで 履歴 → 字幕 (複数行) → 字幕 (1 行) と切り替わる。初めて使う形は今の窓の場所に、同じ文字の大きさで、ロックなしで出る。動かした後は、形ごとに最後に置いた場所・大きさ・角度へ戻る。再起動しても保たれる
- [ ] 見た目が今の small / large と同じに見える (板の色、文字の色、Send / Receive の色、左右寄せ)
- [ ] 1 行の板 (約 1.0 × 0.15 m) が視界の邪魔にならない。訳が 2 行に折り返したとき、原文が上から隠れて訳が残る
- [ ] A−/A＋ で字幕の文字の大きさが変わり、原文・時刻の行も一緒に変わる。16 / 56 で押せなくなる
- [ ] 新しい発言で出て、5 秒後から 2 秒で消える。消える秒を 0 にすると消えない
- [ ] 形を変えたとき・ログ窓を開いたときに、古い字幕や、前の形の縦横比の板が一瞬見えない
- [x] 形のボタンを押すと、ほぼすぐに新しい形が出る (2026-11-17 実機で確認) (出す件が無い 1 行の字幕でも待たされない)。操作バーは消えず、続けて押せる
- [ ] 1 行に切り替えた直後は空の板で、その後に受けた相手の発言から出る。複数行・履歴は過去の発言も出る
- [ ] ロック中は、消えていても見えていても、レーザーが当たらず、点も振動も出ず、VRChat を操作できる
- [ ] ロックしていない字幕は、消えた後でもレーザーで 0.4 秒ほど指し続けると出て、掴める・操作バーが出る
- [ ] 消えた字幕の場所をレーザーが横切っただけでは出ず、その間のトリガー・グリップは VRChat に届く (頭に付けた 1 行の字幕で、正面の VRChat のメニューが押せる)
- [ ] 1 行の字幕で、ログ窓を閉じている間に来た発言は、開き直しても出ない
- [ ] 窓を掴んだまま、まだ使っていない字幕の形へ切り替えると、掴んで動かした先に出る
- [ ] 複数行の字幕で、種類がメイン画面と同じ表記 (送信 / 受信 / 受信 (チャット読み取り)) になる。チャット読み取りの受信が通常の受信より目立たない
- [ ] 時刻・種類の小さい文字が、VR の中で読める
- [ ] 字幕をロックすると、ランチャーのログボタンに錠前が出る。指すと「長押しでロックを外して呼び戻す」と出る。外すと錠前が消える
- [ ] ロックを外した字幕は掴めて、角で大きさを変えられ、指すと操作バーが出る。見えている間に指していれば消えない
- [ ] ランチャーのログボタンの長押しで、ロックが外れて字幕が出る。頭に付けた字幕は、視界の中ならその場、視界の外なら目の前に来る
- [ ] 設定画面を開いたままでも、VR から A−/A＋ が効く
- [ ] VR UI の撮影が PrintWindow になる環境でも、新しい字幕がすぐ出る
- [ ] 字幕を出したままで、ランチャー・キーボード・ポップアップの表示が止まらない

## P4: 検証済みのモデルの一覧 (取得・削除)
`npm run dev-fast` の開発版は `native/target/sidecar-stage` に自分の設定と重みを持つ (インストール版の設定・重みは使わない)。重みが無いので、最初の起動で既定のモデルを取得する。
- [ ] 起動時の自動取得で、翻訳 (nllb-200-distilled-600M) と文字起こしのモデルが取れて、使えるようになる
- [ ] 設定画面で別のモデル (例: Whisper tiny) を選んで取得できる。進み具合が 100% まで進み、完了する
- [ ] 取得の途中で回線を切る (Wi-Fi を切る等) と失敗になり、回線を戻してもう一度取得すると続きから取れる (最初からにならない)
- [ ] 取得元を `https://hf-mirror.com` にしても取れる (中国向けのミラー。endpoint だけで UI は未実装なので、手で試すなら後回しでよい)
- [ ] プロキシを設定した PC でも取れる
- [ ] 大きいモデル (nllb-200-3.3B) の取得が最後まで通る。最後の照合の数秒、進み具合が 100% で止まって見える
- [ ] インストール版の今の重みのフォルダーで新しい版を起動しても、取り直しが起きない
- [ ] 選択中でないモデルを消せる。選択中・取得中のモデルは消せない (endpoint だけで UI は未実装)
