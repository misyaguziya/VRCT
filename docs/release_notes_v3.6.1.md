# [2026/11/10] VRCT v3.6.1 Release 🎉

v3.6.0 の不具合修正版です。VR UI がずれて操作できない問題、受信の文字起こしが止まる問題、プロキシ環境でインストールできない問題などを修正しました。あわせて、字幕オーバーレイの座標ロックを追加しました。

## ✨ 新機能

  * 字幕オーバーレイ（1行・複数行）の座標をロックできるようにしました。設定画面の「位置/回転」の切り替えの右にある鍵ボタンで、それぞれ個別にロックできます。ロック中はVRの中で掴んで動かせず、設定画面からの位置・回転の変更もできません。「初期値に戻す」を押しても、ロック中のオーバーレイの位置はそのまま残ります。

## 🛠️ 改善

  * マイク/スピーカーの「送信するまでに保持する単語数」「ログとして表示するまでに保持する単語数」は、実際には単語数ではなく、文字起こしの結果を溜めておける件数の上限でした。名前を「最大待機メッセージ数」に変え、説明を実際の動作に合わせました（上限を超えると古いものから捨てられます）。動作は変わっていません。
  * 韓国語の翻訳を見直しました（未翻訳・誤訳・助詞の修正）。

## 🐛 バグ修正

  * Windows の「テキストのサイズ」を100%以外にしていると、VR UI の表示がずれてボタンを押せない問題を修正しました。（#125）
  * 翻訳結果が空のときに、受信の文字起こしが止まり、再起動するまで戻らない問題を修正しました。字幕オーバーレイの複数行表示をONにしている場合に起きていました。（#121）
  * VPN などで Windows のプロキシ設定を使っているときに、インストーラーがダウンロードに失敗する（curl のエラー 7）問題を修正しました。（#124）
  * 起動直後に字幕オーバーレイや VR UI のウィンドウを掴んで動かしても、位置が保存されない場合がある問題を修正しました。
  * 動作に影響のない Python の警告で、エラーのダイアログが表示される問題を修正しました。
