# VR キーボード: VR 実機で確かめること

2026-10-21 時点 (feature/vr-keyboard 004ba0aa)。テストやプレビューでは確かめられない、VR の中でだけわかること。
起動は `npm run dev-fast`。

## 指して押す (両手)
- [ ] 両手それぞれにポインタの点が出る
- [ ] 左右の手で交互に速く打っても、押したキーが取りこぼされない
- [ ] 両手でほぼ同時に押したとき、先の押下が離れて後のキーが入る (押しっぱなしにならない)
- [ ] トリガーを引き切る間に手がぶれても、引き始めに指していたキーが入る (特に高さ半分の ▲▼)
- [ ] キーを押すと、押した手が短く振動する
- [ ] BackSpace・◀▶ の長押しでくり返し、トリガーを離す・キーから外れる・グリップを握ると止まる
- [ ] 窓を掴んでいる間・角で大きさを変えている間に、キーが押されたままにならない

## 見た目
- [ ] 幅 0.6 m・キー約 3.6 cm で、打ちやすく読みやすい大きさか (左上の小さい字も読めるか)
- [ ] ▲▼ (高さ約 1.6 cm) が押しにくくないか
- [ ] Shift・言語を変えたときの字の動きが、ちらつきや遅れに見えないか
- [ ] 不透明度 (タイトルバーの ◐) 100/80/60/40 で、後ろが透けて見えるか
- [ ] 辞書の準備中: 進み具合の線が出て、英語に切り替えれば打てる

## 入力
- [ ] 入力欄の文を押すと、その位置にカーソルが移る
- [ ] ▲▼ で送った文を呼び出せる (× で消した後の ▲ は最新から)
- [ ] Shift 1回 + ↵ で改行、Shift ロック中の ↵ は送信
- [ ] × は1回目で色が変わり、続けてもう1回で全部消える
- [ ] 日本語: 空白で変換・次の候補、↵ で確定、変換中の ◀▶ で文節を移る
- [ ] 韓国語: 作りかけの字が強調され、Backspace で字母を1つずつ消せる
- [ ] 中国語: \ キーの印字が「、」で、「、」が入る。简/繁の切り替えで候補の字体が変わる

## 送る
- [ ] 送り先の印 (吹き出し = VRCT で送る): ↵ で翻訳されてチャットボックスに出る
- [ ] 送り先の印 (クリップボード = VRChat に貼る): VRChat の入力欄に貼られる。貼れないときは「コピーだけしました」が出て文が残る
- [ ] 打っている間、VRChat に入力中の表示が出て、送る・消す・キーボードを閉じると消える

## マイクで入力
- [ ] マイクを ON にすると、話した文が送られずに入力欄に入る (韓国語で打った後でも順番が崩れない)
- [ ] VRChat でミュート中 (ミュート同期 ON) でも入る
- [ ] OFF にする・キーボードを閉じる・VR UI を消すと終わり、メインのマイクの状態が元に戻る

## 音
- [ ] キーの音が最初の1打から鳴る (鳴らない・遅れることがないか)
- [ ] 同じキーを続けて押すと同じ音 (Shift を挟んでも)、音量がうるさくないか

## 決めかねている見た目 (触って気になれば直す)
- [ ] 辞書の準備中も ◀▶▲▼・マイクが暗くならない (日本語・中国語ではこの間の ◀▶ は何もしない)
- [ ] 言語の一覧で「한국어」だけ字が細い

## 2026-11-05 の追加 (オーバーレイの土台と、キーボードの範囲の見直し)
- [ ] キーボード・ログ・ランチャー・バーを指している間 (掴み・角で大きさを変えている間も)、その手のトリガー・グリップ・A/B/X/Y が VRChat に届かない。指していない手と、スティックは届く (SteamVR の「Enable global input from overlays」が ON のとき)
- [ ] SteamVR のダッシュボードを開閉した後・コントローラの左右が入れ替わった後・歩きながら/物を持ったまま戻ったときに、押しっぱなしや勝手な掴みが起きず、手を離せば打てる
- [ ] 両手でほぼ同時に別のキーを押すと、両方入る
- [ ] キーを指したときの緑・押したときの見た目が遅れない (60Hz)。ログのスクロール速度が前と同じ
- [ ] 頭の追跡が切れている間の呼び戻しは、追跡が戻ったときに一度だけ目の前へ (古い位置に出ない)
- [ ] VR 設定 > キーボード: 開くショートカット (スティック2回 / B・Y 長押し / B・Y 2回) で開閉できる
- [ ] VR 設定 > キーボード: キーの音の ON/OFF と大きさ、入力中の表示 (VRCT で送るときだけ。貼り付けに切り替えると消える)
- [ ] ▲▼ でメイン画面の入力欄やマイクで送った文も呼び出せる (貼り付けた文は出ない)
- [ ] 日本語: kitte・matcha の促音、kya の BackSpace で「き」、変換中の ◀▶ でカーソルが文字の間に出る、数字の後の「.」、全角数字の候補
