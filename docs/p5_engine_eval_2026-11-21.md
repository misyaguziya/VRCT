# P5 エンジン評価 (2026-11-21)

`docs/rust_next_design_2026-11-15.md` の P5 (speech.cpp / llama.cpp を子プロセスで追加の選択肢にする) を決めるための計測。
手順は `tools/eval_engines/` (`fetch.py` で取得、`run_eval.py` で計測)。版・SHA-256 は `manifest.json`。

## 条件

- PC: RTX 2080 Ti / i7-9700K。VRChat・SteamVR・OBS は閉じて計測 (GPU 使用率 18% の状態から)。
- データ: FLEURS test から ja / en / ko / zh で共通の 50 文 (16 kHz mono 16 bit に変換)。翻訳は同じ文の他言語を正解にする。
- 今のエンジン: VRCT と同じ呼び方 (`native/vrct-backend/examples/eval_local.rs`)。Whisper large-v3-turbo int8、NLLB 600M。GPU は CUDA。
- 候補: speech.cpp v0.11.0 / llama.cpp b12584 の Vulkan 版。HY-MT1.5-1.8B Q4_K_M はモデルカードの推奨設定。
- 遅延は 1 件の中央値 / 90 パーセンタイル (ms)、1 件目の前に 1 回温める。誤り率は日中韓が CER、英語が WER。翻訳は chrF。
- 今の側は CUDA、候補は Vulkan なので、GPU の速さは同じ条件の比較ではない。

## 読み取れること

- 文字起こし: 精度は Whisper turbo と qwen3-asr-1.7b がほぼ同じ (日本語は Whisper、英中は Qwen が少し良い)。
  GPU の速さは qwen3-asr-1.7b が Whisper の約 0.6 倍、0.6b と parakeet-ja はさらに速い (parakeet-ja は 67 ms)。
  CPU では全エンジンが 1 文に数秒かかり、qwen3-asr-1.7b と Whisper は 5〜10 秒で会話には遅い。parakeet-ja だけ CPU でも 1 秒前後。
- 無音の誤出力: Whisper は「ご視聴ありがとうございました」、他も短い相づちを出す。どのエンジンでも VAD や後段の除去は要る。
- 翻訳: HY-MT は ja→en 以外で NLLB より chrF が 5〜10 点高く、GPU では NLLB より速い。CPU では NLLB の約 2〜3 倍遅い。
  ただし HY-MT のライセンス (Tencent HY Community License) は EU・英国・韓国を対象外にしており、配布物の既定や選択肢に入れるのは難しい。
