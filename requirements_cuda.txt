# CUDA (GPU) build requirements.

# ctranslate2 loads at runtime (cublas64_12.dll / cudnn64_9.dll). Until

# used to be hand-maintained copies and had silently drifted apart (the GPU
# build was still pinning a vulnerable sentencepiece and mutable git tags).
